# Jemi M — Portfolio

A professional black-and-white responsive portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — responsive black/white design
- `script.js` — mobile navigation
- `Jemi_Resume.pdf` — resume download

## Deploy on Vercel
1. Upload these files to a GitHub repository.
2. In Vercel, click **Add New → Project**.
3. Import the GitHub repository.
4. Framework Preset: **Other** (or leave Vercel to detect it).
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Click **Deploy**.

This is a static site, so no Node.js installation or build command is required.
